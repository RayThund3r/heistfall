HEISTFALL - bug/resource pass 1 (static audit; not run in a browser)

1. Stuck keys: window blur / tab hide now releases all held keys, mouse and touch stick (no more runaway car after alt-tab).
2. GPU memory leak: removed NPCs, cop cars, cop foot units and old barricades now dispose their geometry/materials (disp3) instead of only leaving the scene.
3. Audio: explosion and thunder noise buffers are generated once and reused (was filling 44k-88k samples with Math.random on every explosion/thunder).
4. NPC-vs-vehicle push-out: cheap distance test now runs before the regex type test (it ran NPCs x vehicles x regex every frame).
5. Interaction prompts: per-frame closures for "Talk to" / "Enter vehicle" are cached, and vehicles beyond reach are skipped before building prompt strings.

Known, deliberately NOT changed (needs a browser to test safely):
- mat() makes a new material per call, but many places recolor materials in place (e.g. wrecked cars turn black), so a global cache would recolor every car. Needs a per-site refactor.
- ~100 functions are defined twice (older layer overridden by newer layer). Harmless at runtime, but dead code and a trap when editing: always edit the LAST definition.

PASS 2 (from your screenshots: black screen on Low/Medium, clipping)
- Render path hardened: bloom failure now disables bloom and falls back to a plain render; a failed render retries without shadows instead of leaving a black canvas; renderer state (autoClear/render target) is reset before every direct render.
- Graphics tiers: Low no longer uses a 16x16 shadow map (floor is now 512) and turns shadows off completely; shadow-map resize is otherwise unchanged.
- NPCs no longer walk through each other or through you (separation push-out, shopkeepers/standing NPCs stay put). Does nothing while you drive/swim/ride.
- Vehicle lights: every car/bus/truck/emergency vehicle (NPC or yours) now projects a soft headlight beam on the road at night (cheap decal, no extra dynamic lights).
- Emotes (B, V, G wheel) are blocked and cancelled while swimming.

PASS 2b: fixed High/Ultra going black (render-target reset must not run while the bloom composer is rendering).

PASS 2c: the new night headlight beams now show only on Low/Medium; High/Ultra keep the original lighting.
